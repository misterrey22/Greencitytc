# Greencitytc
Репозиторій містить приклади тест-кейсів, що демонструють основні підходи до тестування веб-сторінки. У ньому зібрано зразки оформлення тестової документації, сценарії перевірки функціональності та базові техніки тест-дизайну. Матеріали репозиторію можуть бути використані для навчання, практики та вдосконалення навичок тестування.
